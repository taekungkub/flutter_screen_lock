# 📱 Flutter Finger Scan

A new Flutter project implementing **fingerprint authentication** using `local_auth` , `flutter_screen_lock`.

## ✨ Features
- 🔐 Fingerprint authentication
- 🚀 Fast & Secure login
- 🎨 Beautiful UI with Material Design
